# Supplier Evaluation and Segmentation in European Public Procurement: Empirical Evidence from TED Data,

This repository contains the empirical workflow developed for a master's thesis on supplier performance and supplier segmentation in European public procurement using Tenders Electronic Daily (TED) contract award data from 2018 to 2023.

The repository is designed as a reproducible R pipeline. It includes the scripts used to prepare the data, build the supplier-year panel, estimate regression models, and generate clustering-based supplier segments, together with the main final figures and tables.

## Project scope

The empirical analysis focuses on TED Contract Award Notice (CAN) data and addresses two research questions:

- **RQ1:** What factors are associated with supplier performance in European public procurement, measured through the number and total value of awarded contracts at supplier-year level?
- **RQ2:** Can distinct types of suppliers be identified in European public procurement on the basis of their structural characteristics and observed procurement behaviour?

## Workflow overview

The empirical workflow is implemented through five scripts that should be run in numerical order:

1. `R/01_download.R`
2. `R/02_cleaning.R`
3. `R/03_panel_build.R`
4. `R/04_regression.R`
5. `R/05_clustering.R`

A more detailed description of the scripts and their logic is provided in `R/README.md`.

## Public repository note

This public repository is intended to document the empirical workflow in a transparent and accessible way.

- The **R scripts** are versioned and fully visible.
- The **final figures, tables and logs** are included to make the main empirical results easier to inspect without running the full pipeline.
- The **raw data**, **processed intermediate datasets**, and **thesis-writing documents** are not versioned in the public repository.

This choice keeps the repository lighter, more readable, and more suitable for public sharing.

## Data source

The analysis relies on Tenders Electronic Daily (TED) Contract Award Notice data distributed through the EU open data portal. Raw files are reconstructed locally through `R/01_download.R` rather than stored in the repository because of their size.

## Reproducibility

To reproduce the empirical workflow from scratch:

1. Clone the repository.
2. Open the project in R or RStudio.
3. Install any missing packages required by the scripts.
4. Run the scripts in numerical order from `R/01_download.R` to `R/05_clustering.R`.

The workflow is sequential, so each script depends on outputs generated by the previous one.

## Thesis context

This repository contains the empirical analysis only. The thesis manuscript, appendix drafting files, and other writing materials are maintained separately from the public replication repository.
