# Logs

This folder contains the diagnostic and validation logs generated by the empirical pipeline.

The log files are intentionally kept small and are included in the public repository because they help document data quality, sample construction, and model inputs used throughout the thesis.

## Folder contents

The main log files are generated by the following scripts:

- `R/01_download.R` creates `download_log_can.csv`.
- `R/02_cleaning.R` creates `cleaning_log.csv`, `id_award_conflicts.csv` and `cpv_division_validation.csv`.
- `R/03_panel_build.R` creates `panel_log.csv`, `win_country_code_validation.csv`, `win_country_code_validation_summary.csv`, `crit_code_validation.csv`, `crit_code_by_year_validation.csv` and `crit_code_by_procedure_validation.csv`.
- `R/04_regression.R` creates `regression_log.csv`.
- `R/05_clustering.R` creates `clustering_log.csv`.

## Purpose of the logs

These files provide a record of:

- which raw files were found or downloaded;
- how many observations were removed during cleaning;
- how the supplier-year panel was constructed;
- which criterion codes and country codes were validated;
- the sample sizes and diagnostics used in the regression and clustering stages.

They are useful for transparency and for checking that the empirical pipeline ran as intended.

## Notes

- The logs are generated automatically and should not be edited manually.
- If a log file is missing, rerun the corresponding script in `R/`.
- The folder is documented here so that the public repository clearly shows how the analysis was prepared.
