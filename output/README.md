# Output files

This folder contains the public outputs generated by the empirical pipeline.

The files here are the final figures and tables used to summarize the main results of the thesis. They are generated automatically by the scripts in `R/` and are included in the repository so that the results can be inspected without rerunning the full pipeline.

## Folder structure

- `figures/` contains the main graphical outputs.
- `tables/` contains the main summary tables and regression/clustering outputs.

## Relation to the pipeline

The outputs in this folder are produced by the later stages of the workflow:

- `R/04_regression.R` creates descriptive statistics, the correlation matrix, regression tables, the correlation figure, the consortium collinearity diagnostic and the specialization-share/HHI collinearity check.
- `R/05_clustering.R` creates the clustering diagnostics, cluster summaries, centroid tables, and cluster figures.

The underlying raw and processed data are stored in `data/raw/` and `data/processed/`.

## Public outputs

The repository includes both figures and tables because they provide a compact, readable record of the empirical findings.

The outputs include:

- correlation matrix figure and table;
- regression result tables;
- specification diagnostic tables;
- elbow and silhouette diagnostics;
- cluster summary tables;
- cluster centroid tables;
- cluster interpretation and robustness tables;
- cluster scatter and specialization figures.

## Notes

- The files in this folder are generated automatically and should not be edited manually.
- If an output file is missing, rerun the corresponding script in `R/`.
