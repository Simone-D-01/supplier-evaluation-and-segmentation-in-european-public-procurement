# Figures

This folder contains the public figures generated by the empirical pipeline.

The figures are included to make the main results of the thesis easy to inspect visually without rerunning the full analysis.

## Contents

### Regression outputs

- `correlation_matrix.png` — correlation heatmap for the main regression variables.

### Clustering outputs

- `clustering_elbow.png` — elbow diagnostic for selecting the number of clusters.
- `clustering_silhouette.png` — silhouette diagnostic based on repeated subsamples.
- `cluster_scatter.png` — supplier segmentation scatter plot for the main clustering solution.
- `cluster_specialization.png` — supplier segmentation scatter plot focusing on specialization and cross-border orientation.

## Notes

- These files are generated automatically and should not be edited manually.
- If a figure is missing, rerun the corresponding script in `R/`.
- The figures are meant to complement the tables in `output/tables/`.
